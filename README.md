# Лабораторная работа №2: Проектирование REST API и спецификация OpenAPI 3.0 (Swagger)

* **Дисциплина:** Разработка серверных приложений
* **Студент:** Вариант 23
* **Тема проекта:** Сервис мониторинга доступности сайтов (Uptime Monitor) — *«UptimePulse»*

---

## Описание работы
Во второй лабораторной работе спроектирован контракт взаимодействия клиентской и серверной частей (REST API) для индивидуального сквозного проекта:
* Разработаны 8 REST-эндпоинтов, охватывающих аутентификацию, управление сайтами (CRUD), получение истории пингов и журнал аварий.
* Составлена спецификация по стандарту **OpenAPI 3.0 (Swagger)** с подробными схемами запросов, ответов и кодов ошибок.
* Спецификация протестирована на отсутствие синтаксических ошибок в Swagger Editor.
