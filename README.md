# Лабораторная работа №1: Проектирование архитектуры серверного приложения

* **Дисциплина:** Разработка серверных приложений
* **Студент:** Вариант 23
* **Тема проекта:** Сервис мониторинга доступности сайтов (Uptime Monitor) — *«UptimePulse»*

---

## Описание проекта
**UptimePulse** — сервис для регулярного мониторинга доступности и времени отклика веб-сайтов и REST API. Сервис пингует заданные URL по расписанию, строит графики доступности и оповещает владельцев сайтов об авариях через Telegram и Email.
